# 🚀 منصة تكنو هب (TechnoHub & TechGear)

> **الرسالة التسويقية (Slogan):**  
> *"منفذك الأول لأجهزة اللابتوب، قطع الغيار، وجميع حلول التوصيل الاحترافية."*

منصة تجارة إلكترونية احترافية متخصصة تقدم حلولاً شاملة لعشاق ومحترفي التكنولوجيا؛ حيث تجمع بين بيع أجهزة الكمبيوتر المحمول (جديدة ومستوردة/فرز أول)، اللوحات الأم (Motherboards)، ومختلف أنواع التوصيلات والكابلات الدقيقة (4K & Type-C)، بالإضافة إلى وسائط التخزين الرقمية.

---

## 🌟 مميزات المشروع (Key Features)

### 1. واجهة المتجر للزوار والعملاء (Storefront UI):
- **Hero Banner Slider:** بنر متحرك عريض يعرض العروض الترويجية والمنتجات الحصرية.
- **شبكة الأقسام السريعة:** لابتوبات، لوحات أم، كابلات ومحولات، فلاشات وتخزين، شواحن وإكسسوارات.
- **البحث الذكي برقم الموديل (Part Number P/N):** إمكانية البحث المباشر باسم المنتج أو رقم القطعة الدقيق مع قائمة اقتراحات فورية.
- **أقسام مخصصة:** الأكثر مبيعاً (Best Sellers) ووصل حديثاً (New Arrivals).
- **صفحة تفاصيل المنتج:** معرض صور عالي الدقة، جدول مواصفات فنية، قائمة التأكد من التوافق قبل الشراء، ومؤشر حالة المخزون.
- **الشراء المباشر والطلب السريع عبر الواتساب:** زر إرسال طلب مجهز تلقائياً بالتفاصيل عبر الواتساب.
- **تجربة الشراء والشحن كـ زائر (Guest Checkout):** إتمام الطلب بدون تعقيد تسجيل الدخول.
- **خيارات دفع مرنة:** الدفع عند الاستلام (COD)، المحافظ الإلكترونية (فودافون كاش / InstaPay)، والبطاقات البنكية.

### 2. لوحة تحكم الإدارة (Admin Dashboard):
- **إدارة المنتجات والنشر:** نموذج ديناميكي لإضافة وتعديل المنتجات مع باني المواصفات الفنية (Dynamic Technical Specs Builder).
- **إدارة المخزون والتنبيهات:** خصم تلقائي للكميات عند تأكيد كل طلب وتنبيهات المخزون المنخفض (Low Stock Alert).
- **إدارة الطلبات والشحن:** متابعة الطلبات الجدد والمكتملة مع إمكانية تحديث حالة التوصيل.
- **طباعة بوليصة الشحن والفاتورة بضغطة زر:** طباعة فاتورة الشراء الرسمية وبوليصة الشحن مع محاكاة للباركود جاهزة للطباعة أو الحفظ كـ PDF.
- **الإحصائيات والتقارير:** ملخص الأرباح، عدد الطلبات، والمنتجات الأكثر طلباً.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** Next.js 16 (App Router) + TypeScript
- **Styling:** Tailwind CSS + Custom High-Tech Glassmorphism
- **Icons:** Lucide React
- **Animations:** Canvas Confetti & CSS Transitions
- **State & Persistence:** React Context + LocalStorage Sync

## 📌 خطوات رفع المشروع على جيت هاب (GitHub) وربطه بـ فرسيل (Vercel)

### أولاً: رفع الكود على حسابك في GitHub

افتح مبدل الأوامر (Terminal) في مجلد المشروع وقم بتنفيذ الأوامر التالية:

```bash
# 1. تهيئة مستودع Git (في حال لم يكن مهيئاً)
git init

# 2. إضافة جميع الملفات
git add .

# 3. عمل الحفظ الأول (Commit)
git commit -m "Initial commit - TechnoHub E-Commerce App"

# 4. تغيير اسم الفرع الرئيسي لـ main
git branch -M main

# 5. ربط المستودع برابط مستودعك على جيت هاب (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/YOUR_USERNAME/techno-hub.git

# 6. رفع الكود
git push -u origin main
```

---

### ثانياً: ربط المستودع بـ فرسيل (Vercel) للنشر المباشر

1. سجل الدخول إلى موقع [Vercel.com](https://vercel.com).
2. اضغط على **"Add New"** ثم اختر **"Project"**.
3. قم بصلة حساب **GitHub** الخاص بك واختر المستودع `techno-hub`.
4. اترُك الإعدادات الافتراضية كما هي (Framework Preset: Next.js).
5. اضغط على **"Deploy"**.
6. في غضون ثوانٍ قليلة، سيتم نشر موقعك وستحصل على رابط مباشر يعمل عالمياً مجاناً! 🚀
